DexINF

Developed with YouTube

DexINF is a private desktop tool used only by its owner to publish videos to the owner's own YouTube channels. It uses the YouTube API Services (YouTube Data API v3) to upload videos, set titles, descriptions and thumbnails, and schedule publication.

DexINF é uma ferramenta pessoal, usada apenas pelo próprio dono, para publicar vídeos nos seus próprios canais do YouTube usando os Serviços de API do YouTube. Ela roda no computador do dono, não é vendida, não tem cadastro de usuários e não coleta dados de terceiros.

How it works

  • The owner connects a channel once with Google sign-in (OAuth 2.0).
  • The owner approves videos in the local dashboard, or turns on automatic daily scheduling for their own channel.
  • DexINF uploads the approved video with videos.insert, sets the thumbnail with thumbnails.set and schedules it with status.publishAt.
