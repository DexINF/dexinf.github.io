DexINF

DexINF é uma ferramenta pessoal, usada apenas pelo próprio dono, para organizar a produção dos seus vídeos e enviá-los aos seus próprios canais do YouTube usando a API oficial do YouTube (YouTube Data API v3).

A ferramenta roda no computador do dono. Ela não é vendida, não tem cadastro de usuários e não coleta dados de terceiros.
